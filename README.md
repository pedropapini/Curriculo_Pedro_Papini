# Currículo online — Pedro Papini Almeida

Site pessoal de currículo feito em HTML e CSS, pronto para publicação no GitHub Pages.

## Arquivos

- `index.html` — página principal
- `style.css` — estilos do site
- `Curriculo_Pedro.pdf` — coloque aqui o PDF do currículo

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `Curriculo_Pedro.pdf`.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

Depois, o site ficará disponível em um endereço no formato:

`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

## Personalização

No `index.html`, substitua o comentário da seção de contato pelo seu LinkedIn quando quiser.

O endereço residencial não foi colocado no site público.
